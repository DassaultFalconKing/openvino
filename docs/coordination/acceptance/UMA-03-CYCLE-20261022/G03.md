# U2-G03 — concurrent miss + eviction under stream

**Status:** **PASS**  
**Test:** `moe_otd_uma02.U2_G03_concurrent_miss_eviction_under_stream`  
**Env:** `OTD_RESIDENT_USM_HOST=1` `MOE_OTD_PERF_LOG=1`

## What was proven

1. **Simultaneous lease:** `try_acquire_simultaneous({0,1,0})` on capacity=2 fills both experts; duplicate id maps to same slot.
2. **Overflow reject:** `try_acquire_simultaneous({0,1,2})` returns nullopt; cache size stays 2; existing hits preserved.
3. **Eviction:** capacity=1 fill E0 → GPU digest → acquire E1 reuses slot; E1 is hit; warm re-acquire E1 does not increment `expert_loads`.
4. **No false hit:** re-acquire E0 increments `expert_loads` (miss); digest restored to pre-eviction E0 bytes; subsequent E1 acquire also misses.

## Pitfall recorded

`LRUCache::lookup()` **inserts on miss**. Probing an absent expert with `lookup` can evict a filled peer. G03 asserts use warm/miss `expert_loads` deltas instead of probing absent ids.

## Non-claims

Not a multi-threaded soak. Not a proof against all use-after-evict races under overlapping GEMM kernels without finish.
